# project_agrovis_gs
AgroVis é um ecossistema tecnológico que liga a economia espacial aos desafios da agricultura na Terra. Integra Visão Computacional (OpenCV), Machine Learning preditivo, uma API Core em .NET (C#), Cibersegurança e um aplicativo móvel em React Native para monitorização de lavouras. Desenvolvido para a Global Solution 2026 da FIAP.
